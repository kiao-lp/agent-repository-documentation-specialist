# Documentation presentation

Optimize human readability through conciseness and the use of words in their literal meaning.

Embed key phrases in prose to summarize the surrounding ideas in a few words. Bold the words that carry the meaning.

- For a simple sequence, prefer a numbered list and use key phrases.
- For a complex sequence, use a sequence diagram or a communication diagram.
